# QWYTHOS Telegram Bot — التشغيل والتشخيص

## لماذا لا يرد البوت عند إغلاق الجهاز؟

البوت **يعمل على ماك أحمد** (MacBook Air M2)، وليس على تلغرام نفسها.
تسلسل الاعتماد:

```
هاتفك → تلغرام (سيرفرات) → ماك أحمد → Groq API → الرد → ماك → تلغرام → هاتفك
```

عندما **يُغلق الغطاء أو ينام الماك**، يتوقف `getUpdates` (السحب من تلغرام)،
فتُخزَّن رسائلك على سيرفرات تلغرام ولا تُسلَّم حتى يستيقظ الماك.

**هذا ليس عطلاً — هذا طبيعة العمل المحلي.**

## الحلول حسب الحالة

### 1. منع النوم عند الخمول (مُطبَّق ✅)

`start-bot.sh` يشغّل البوت تحت `caffeinate -is`:
- `-i` يمنع نوم النظام عند الخمول (يعمل على البطارية والشاحن)
- `-s` حماية إضافية على الشاحن

هذا يمنع النوم **بسبب الخمول** فقط.

### 2. إغلاق الغطاء (Lid Close) — يحتاج صلاحية root

على Apple Silicon، **إغلاق الغطاء يُنيم الجهاز دائماً**، و`caffeinate` لا يتجاوزه.
الحل الوحيد هو تعطيل النوم كلياً:

```bash
sudo pmset -a disablesleep 1     # تعطيل النوم (يشمل إغلاق الغطاء)
sudo pmset -a disablesleep 0     # إعادة الوضع الطبيعي
```

⚠️ **تحذير:** مع `disablesleep 1` سيظل الماك يعمل والغطاء مغلق —
قد يسخن داخل الحقيبة. استخدمه فقط على سطح مستوٍ جيد التهوية.

### 3. الحل الأمثل: تشغيل البوت على سيرفر 24/7

تشغيل البوت على استضافة دائمة (VPS مجاني/رخيص، أو Hugging Face Spaces)
يجعله يعمل دون الاعتماد على ماك أحمد إطلاقاً.

**خيارات مجانية:**
- **Oracle Cloud Free Tier** — VM دائمة مجاناً (يحتاج بطاقة للتحقق فقط)
- **Hugging Face Spaces** — Docker Space مجاني (يتوقف عند الخمول، لكنه يستيقظ تلقائياً)
- **Railway / Render** — طبقات مجانية محدودة

## التشغيل المحلي

```bash
# الخدمة تعمل تلقائياً عبر launchd
launchctl list | grep qwythos-telegram

# إعادة تشغيل
launchctl kickstart -k gui/$(id -u)/com.user.qwythos-telegram

# إيقاف مؤقت
launchctl unload ~/Library/LaunchAgents/com.user.qwythos-telegram.plist

# السجل
tail -f /tmp/qwythos-bot.err
```

## أوامر البوت

| الأمر | الوظيفة |
|-------|---------|
| `/start` | رسالة الترحيب والقدرات |
| `/status` | حالة الجهاز: البطارية، النوم، منع النوم، مدة التشغيل |

## حدود تلغرام

- **4096 حرف** لكل رسالة — البوت يقسّم الردود الطويلة تلقائياً (`send_long_message`)
- **20 MB** لكل ملف مرفوع
- السحب (`getUpdates`) وليس Webhook — لا يحتاج IP عام
